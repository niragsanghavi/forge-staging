Archivo — Omnibus-Type
SIL Open Font License 1.1 (see OFL.txt)
https://github.com/googlefonts/Archivo

Self-hosted rather than loaded from Google Fonts: no third-party
request on page load, and no dependency on a CDN staying reachable.
Latin subset, weight 800 only (~34 KB). The @font-face declares the
range 700-900 so the page's existing font-weight:900 display rules
resolve to real outlines instead of a synthesised faux-bold.
